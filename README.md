# KYC Liveness Test iOS (Dopamine / RootHide)

Ứng dụng iOS mô phỏng quy trình kiểm tra Flash Liveness của các giải pháp eKYC (FaceTec, Sumsub, VNPT, FPT...).

## Tính năng
- Camera Preview trực tiếp ở chế độ selfie (kết nối trực tiếp với luồng mediaserverd của VCAM).
- Khung Oval căn chỉnh khuôn mặt chuẩn ngân hàng.
- Mô phỏng nhịp chớp màu 6 dải màu chuẩn (Đỏ, Xanh lục, Xanh lam, Vàng, Cyan, Tím hồng).
- Giúp kiểm tra trực quan hiệu ứng bắt màu và phản xạ ánh sáng của VCAM iOS Tweak.
